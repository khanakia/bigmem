Build guide · desktop & workstation · from parts

Every component to build a high-memory desktop or workstation.

The full parts list — case, motherboard, CPU, RAM, cooler, PSU, storage, GPU — what each does, what must match, rough Hong Kong prices, and two sample builds. For socketed CPUs (AM5 Ryzen, Threadripper, Xeon-W); pick your chip from the Reference Table.

⚠️ The one big exception: the Ryzen AI Max+ 395 (and all Strix Halo / mini-PC APUs) can't be built from parts — the chip and its 128 GB RAM are soldered to the board, sold as one sealed unit. There's no socket and no RAM slots. If you want a 395, you buy a finished mini-PC, not parts. This build guide is for the socketed route (9950X, Threadripper, Xeon-W), where you *can* mix and match — and get more RAM headroom + upgradability in exchange for size and power draw.

Compatibility rules (the things that must match)

  • Socket: CPU socket = motherboard socket. AM5 (Ryzen desktop), sTR5 (Threadripper), LGA4677 (Xeon-W). Wrong socket = won't fit.
  • RAM type + capacity: DDR5 only (current). Desktop uses UDIMM; Threadripper/Xeon-W use RDIMM (ECC) — not interchangeable. Max RAM is set by the board's DIMM slots, not just the CPU: 2 slots ≈ 128 GB, 4 slots ≈ 192–256 GB. Want 192 GB on a desktop → get a 4-slot board.
  • PSU wattage: add up the parts (CPU TDP + GPU + rest) and add ~30% headroom. A 170 W CPU + a GPU wants ~750–850 W; a Threadripper workstation wants 1000 W+.
  • Case form factor: the case must accept the board size (ITX < mATX < ATX < E-ATX). Also check cooler height and GPU length clearance.
  • Cooler ↔ CPU: the cooler needs the right socket bracket and a TDP rating at/above the CPU. Threadripper needs a physically larger TR cooler.
  • iGPU or not: Ryzen desktop chips have a small display iGPU (you can boot without a graphics card). Threadripper and Xeon-W have none — you MUST add a GPU just to get a picture.

Platform longevity — will my board still take next year's CPU?

The real cost of a build isn't the first purchase — it's whether you can drop in a newer CPU in 3 years and keep the board + RAM, or have to replace everything. This is where AMD's desktop socket wins big.

Bottom line for the "I don't want to re-buy everything" worry: no motherboard takes every CPU — socket, chipset and RAM type are a matched set, and they change on purpose. The closest thing to future-proof is AM5: buy the board + DDR5 once, and for years you upgrade only the CPU. The 395 mini-PC is the opposite — cheapest today, but a sealed appliance you replace whole. Pick AM5 if upgrade-longevity matters most; pick the 395 if size, efficiency and lowest upfront price win. Reality check vs a pre-built 395 mini-PC: the 128 GB AM5 build (~HK$14,100) lands near a pre-built 395 mini-PC (~HK$16k from mainland) — and gives you upgradability + a 256 GB RAM ceiling + a real GPU slot. The trade-offs: it's big, draws ~170 W+, and has no battery (add a UPS for your outages), whereas the 395 box is tiny, efficient, and unified-memory. Pick the build if you value expandability; pick the mini-PC if you value size/efficiency.
