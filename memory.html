LPDDR — low-power, soldered (mobile & APUs)

HBM — high-bandwidth 3D-stacked (AI & HPC)

High Bandwidth Memory — DRAM dies stacked vertically and placed on-package next to the processor via an interposer. The fastest memory made; extremely expensive. Powers AI accelerators & supercomputers — e.g. the Nvidia GH200 in the table pairs 141 GB HBM3e with 480 GB LPDDR5X.

Which memory is used where

  • Desktop PC: DDR5 UDIMM (CUDIMM for the fastest kits). Upgradeable.
  • Laptop: DDR5 SO-DIMM or LPCAMM2 (upgradeable), or LPDDR5X soldered (thin/light, fixed).
  • Mini-PC / APU (Strix Halo, GB10): LPDDR5X soldered — unified with the iGPU, fast, but fixed capacity.
  • Workstation / server: DDR5 RDIMM / LRDIMM (ECC); MRDIMM on the newest Intel Xeon 6.
  • Graphics card: GDDR6 / 6X / 7 soldered on the GPU (or HBM on datacenter GPUs).
  • AI accelerator / supercomputer: HBM3E on-package.
  • Phone: LPDDR5X on-package.
  • CPU cache (L1/L2/L3): SRAM — not "RAM you buy"; it's built into the chip (see below).

Other memory worth knowing

  • SRAM (Static RAM): the CPU's on-chip cache (L1/L2/L3) and AMD's "3D V-Cache". Fastest & lowest-latency memory, but tiny and expensive per bit — you never buy it separately.
  • Optane / 3D XPoint (Intel DCPMM): persistent memory that sat between RAM and SSD (survives power loss). Used on some Xeons for huge in-memory DBs — discontinued in 2022.
  • Emerging non-volatile RAM — MRAM, ReRAM, FeRAM: retain data without power; used in niche/embedded/industrial roles, not mainstream PCs yet.
  • Not RAM (common confusion): NAND flash (SSDs/USB) is storage, not memory — it's slower, non-volatile, and byte-addressing works differently. RAM loses its contents when powered off; storage doesn't.

So which is fastest?

Two different "fast": latency (how quickly it responds) vs bandwidth (how much it moves per second). Ranking by bandwidth: HBM3E (~1.2 TB/s per stack, multi-TB/s aggregate) > GDDR7 (~1 TB/s across a GPU) > LPDDR5X in a wide-bus APU (~256 GB/s, e.g. Strix Halo) > DDR5 (~50–70 GB/s per channel; more with 8–12 channels on servers). By latency, on-chip SRAM cache wins by far. For CPU work (the whole point of the table) you want capacity + enough DDR5 bandwidth; for LLMs you want bandwidth (unified LPDDR5X or HBM); for graphics you want GDDR.
