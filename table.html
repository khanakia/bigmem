How to read this table — columns · formulas · caveats
HOW TO READ THIS TABLE — every non-Apple CPU / APU / SoC that supports ≥128 GB RAM. Default view is a flat, globally-sorted list; use GROUP BY to bucket by segment / vendor / unified. Click a column header to sort, click a row to expand full specs, benchmarks & a why-pick/why-not note. All state deep-links to the URL so a filtered view is shareable.
Columns.  Max mem = vendor controller maximum (caveat below).  Chan = memory channels = parallel memory pipes → sets bandwidth; the board decides DIMM slots (up to 2 per channel), soldered parts show "—".  BW = memory bandwidth (DDR/LPDDR path).  Cores = physical cores (P+E for Intel hybrids) / threads (no "/T" = no SMT).  PCIe = CPU lanes × generation (expansion for GPUs/SSDs — unrelated to RAM).  CPU Mark = PassMark multi-thread score — overall throughput at parallel work (compiles, containers, VMs, many tabs); higher = faster.  Value = CPU Mark ÷ price = compute per dollar (e.g. Core Ultra 7 265K = 58,603 ÷ $394 ≈ 149); higher = better bang-for-buck.  Price = see "what price means" below.
In the row expand:  Single-thread = PassMark per-core rating (UI snappiness / sequential steps — a minor tiebreaker; it barely varies across modern chips).  Perf/watt = CPU Mark ÷ TDP (efficiency, heat & running cost for an always-on box).  Plus memory bandwidth, channel config, socket/platform, TDP, process node, launch year.
What "price" means — two different things. Socketed parts (desktop / HEDT / workstation / server) = CPU only; you still add motherboard, RAM (128–192 GB of DDR5 is a big extra), SSD, PSU, case. Soldered parts (laptop / mini-PC — Snapdragon, Strix Halo, GB10, 285H/HX, Orange Pi) = whole-device estimate, since the chip isn't sold on its own, and a max-RAM config costs more than the listed ballpark. So Value only compares apples-to-apples within the same type, and many prices are estimates — verify in the shop.
Value ≠ "best for you." A cheap 4-core (i3-14100, value 113) scores high but is too weak for heavy Docker. Use Value to compare chips of similar capability, then confirm Cores & Max mem fit your workload.
Unified vs split (MEM column).  UNI = one physical pool shared by CPU + GPU/NPU (matters for local-LLM / GPU work; caps at 128 GB on everything non-Apple except the slow Orange Pi).  SPLIT = separate CPU & GPU memory, reaches 192 GB → multiple TB via standard DIMMs. For CPU/dev workloads SPLIT is what you want — no premium for GPU-shared bandwidth you won't use. Core Ultra 9 285HX is SPLIT — that tiny iGPU carve-out is exactly why it reaches 192 GB on standard SO-DIMMs.
Memory & bandwidth caveats. Max-mem & bandwidth are manufacturer maximums (vendor spec sheet / Intel ARK) — the controller ceiling, not a guaranteed config; real capacity depends on board DIMM slots, density & BIOS/AGESA. On UNI parts the GPU-allocatable share is below the total (~96/128 GB Windows, ~110 GB Linux on Strix Halo). Bandwidth shown is the DDR/LPDDR path; HBM tiers (GH200, Xeon Max) are separate & far faster — see the row note.
Benchmark coverage & freshness. CPU Mark / single-thread from cpubenchmark.net (PassMark), ~Jul 2026. Arm/NPU superchips (GB10, GH200/GB200, Orange Pi) & unreleased parts (EPYC Venice) aren't on PassMark → shown "—". Server scores are single-socket; the newest SKUs (Threadripper 9000, Granite Rapids, Turin) have thin sample sizes that drift over time; a few server parts list only single-thread, so their CPU Mark is "—".
Scope & exclusions. Apple M3 Ultra (512 GB / 819 GB/s unified) omitted per no-Apple rule. Meteor Lake 185H dropped (96 GB < 128 GB). Snapdragon X gen-1 excluded (64 GB cap) — X2 Elite (128 GB) is in. AMD Zen3/3+ mobile (Ryzen 5 5600U, 5 7530U, 7 7735U) excluded — memory controller caps at 64 GB. Phoenix/Hawk Point (7640U → 8945HS) included: AMD-spec 256 GB max, so 128 GB via 2×64 SO-DIMM if the mini-PC has SO-DIMM slots (soldered-LPDDR boxes are locked lower). Incoming: EPYC Venice launches ~today (listed, specs partial); Ryzen AI Max 400 "Gorgon Halo" ~Q3 2026; Granite Rapids-WS. Server SKUs are representative per generation, not every OPN.
